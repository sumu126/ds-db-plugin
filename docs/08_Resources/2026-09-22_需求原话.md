# 需求原话记录

- **日期**：2026-09-22
- **来源**：与插件维护者的对话（本轮多连接改造完成后）

## 原始表述

1. 「因为我们后期可以扩展这个 ds-db 插件，所以我们的页面应该优化一下，例如在我们的插件配置页面中应该是多种卡片悬浮的方式展示给用户，并且对应的插件页面的右上角应该有新建连接按钮，点击弹窗中显示支持的数据库类型，这样才是一个健壮的插件。」
2. 「另外插件注册的设置侧边菜单名称也不要改叫 MySQL 了，直接中文数据库管理吧。」
3. 「我们最终的目的就是让这个插件可以提供给其他开发者自由的开发以及添加自己想要添加的数据库类型。」
4. 「你可以新建一个目录专门存放你的文档。」
