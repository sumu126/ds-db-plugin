# 001_方言扩展能力_设计方案

> 目标：第三方开发者不改本仓库即可发包增加一种数据库类型。本文给出三条 seam 的补全方案与兼容性策略。

## 1. 现状：seam 覆盖到哪了

| 关注面 | 是否已抽象 | 落点 |
| --- | --- | --- |
| 驱动与会话 | ✅ | `dialect.open(connection)` |
| 元数据 SQL 与行投影 | ✅ | `databases/tables/columns/indexes/createStatement/version` |
| 占位符与驱动绑定 | ✅ | `DialectStatement.values` |
| 行数上界语法 | ✅ | `applyRowLimit` |
| 标识符引用 | ✅ | `quoteIdentifier` |
| 词法与只读规则 | ✅ | `rules`（`sql-guard.ts` 消费） |
| 模型可见文案 | ✅ | `label` / `rowBoundHint` / `families` / `systemDatabases` |
| 注册与卸载 | ✅ | `ctx.databaseDialects.register()` 返回 disposer |
| **能力等级** | ❌ | 方言被要求实现全部方法，缺一不可 |
| **连接配置字段** | ❌ | 页面与 schema 写死 MySQL 形状 |
| **分发** | ❌ | `@deepseek-ai/*` 是裸导入，未声明依赖 |

结论：**执行层已打通，配置层与能力层没抽出来**——这正是「能加第二种库」之前必须补的两刀，加上分发这三件事构成本方案的全部范围。

## 2. 设计一：能力声明（F2）

### 2.1 类型

```ts
/** 一种数据库可能提供、也可能不提供的元数据能力。 */
export type DialectCapability =
  | 'databases'      // 能列出可见的库
  | 'tables'         // 能列出表与视图
  | 'columns'        // 能描述列
  | 'indexes'        // 能列出索引
  | 'createStatement'// 能给出建表语句原文
  | 'estimatedRows'  // 能给出行数估算
  | 'charset'        // 能给出字符集/排序规则
  | 'version'        // 能回答版本号
  | 'sample'         // 能低成本采样若干行
  | 'explain'        // 能给出执行计划
```

`DatabaseDialect` 增加：

```ts
/** 本方言真正提供的能力；未声明的能力工具会降级，不会去执行。 */
readonly capabilities: ReadonlySet<DialectCapability>
```

注册时校验：能力键必须来自上述集合，未知键直接抛错（fail loud）。

### 2.2 工具降级规则

| 工具 | 依赖能力 | 缺失时行为 |
| --- | --- | --- |
| `db_databases` | `databases` | 直接拒绝并说明该方言不支持 |
| `db_tables` | `tables` | 拒绝；`estimatedRows` 缺失则该列为 `null` |
| `db_describe` | `columns` | 拒绝；`indexes` 缺失 → 空数组；`createStatement` 缺失 → 该字段省略 |
| `db_query` | 无（仅需 `rules`） | 不受影响 |

输出 schema 相应改为可选字段（`required` 列表里移除 `createStatement`），保证「降级」也是契约的一部分，模型能据此判断。

### 2.3 描述文案

工具描述在注册时写定。能力缺失时不能改描述（描述已固化），因此**描述里不写具体能力清单**，改为在工具结果中给出一行说明；`db_describe` 缺失时返回 `createStatement: undefined` 本身就是信号。

## 3. 设计二：配置字段可扩展（F3）

按决策记录选定**方案 B：通用字段 + `extra`**。

```ts
/** 方言声明的一个额外连接字段。 */
export interface DialectConfigField {
  /** 存进 `extra` 的键。 */
  key: string
  /** 控件类型。 */
  kind: 'text' | 'number' | 'secret-ref'
  /** 默认值。 */
  default: string | number
  /** 是否必填；为空时工具调用报错并指明该字段。 */
  required: boolean
  /** 页面提示文案（由字典提供键，见下）。 */
  hintKey?: string
  /** 该字段是否承载敏感值（渲染为只写控件）。 */
  sensitive?: boolean
}
```

`DatabaseDialect` 增加 `readonly configFields: readonly DialectConfigField[]`；`ConnectionProfile` 增加 `extra: Record<string, string | number>`。

**页面渲染**：新建/编辑弹窗在选定方言后，除通用字段外追加 `configFields` 声明的控件，值写入 `extra`。校验复用 `required` 与 `kind`。

**文案归属**：方言作者无法往本插件的字典里加键（字典随构建产物分发）。因此 `hintKey` 缺省时回退到方言自带的 `label`（方言可携带一份自己的双语文案 `copy: { zh, en }`）—— 这一点写入 API 文档，避免方言作者产出硬编码英文。

**已知限制**：SQLite 这类无 host/port 的方言仍会看到通用字段；触发条件见决策记录，届时升级方案 A。

## 4. 设计三：分发可安装（F4）

### 4.1 本插件补声明

`package.json` 增加 `peerDependencies`：`@deepseek-ai/cordis`，以及实际用到的 `dsh-tools` / `dsh-settings` / `dsh-credentials`（浏览器侧用 `peerDependenciesMeta.optional` 标注，因为无头部署不加载浏览器半边）。

`mysql2` 保持 `dependencies`（它是本插件自带方言的驱动；第三方方言各自声明自己的驱动）。

### 4.2 第三方方言包

```json
{
  "name": "dsh-dialect-postgres",
  "peerDependencies": { "dsh-ds-db": ">=0.2.0" },
  "dependencies": { "pg": "^8.13.0" },
  "dsh": { "client": { "platform": "web" } }
}
```

### 4.3 验证路径

必须在**打包版 dsh**（非源码 tsx 启动）上实测：

```sh
dsh plugin --profile web add ./dsh-dialect-postgres
dsh --profile web --dump-config   # 应看到该方言包贡献的层
```

当前已知阻塞：源码态靠 tsx 的 `paths` 解析裸导入，打包态没有该机制——M1 的验收就是打通这条路径。

## 5. 兼容性策略

### 5.1 既有配置零迁移

- 组合层 `cordis.yml` 的平铺字段继续有效（已实现）；新增 `connections` 也继续有效。
- 已保存的 `ConnectionProfile` 缺 `extra` 时按 `{}` 处理（schema 给默认值），用户无需重新录入。

### 5.2 方言后注册导致的描述滞后

工具描述在注册时写定；后注册的方言只能让**调用**立即生效，**描述文案**滞后到下次重载。这是既有取舍（`described` 与 `dialect()` 在 `DatabaseToolsFace` 里是两个成员）。

缓解：把工具描述中方言相关的部分收敛到「最少必要」（自称 `label` 与语句族），其余改为运行期结果里体现；并在 API 文档明示该行为，让方言作者知道「改名不会立刻出现在描述里，但不影响调用」。

### 5.3 只读红线

新增方言必须提供 `rules`（词法 + 禁止项）。`sql-guard` 的结构保持方言中立、规则由方言喂，因此新方言不能绕过只读判定。M5 的自检套件会把「只读判定」作为强制用例。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 第三方方言放宽只读规则 | 安全 | 自检套件强制用例；文档写明红线；评审模板 |
| 能力键集合过早固化 | 演进受阻 | 能力键可扩展；注册时校验而非编译期穷举 |
| `extra` 字段类型漂移 | 配置损坏 | 值限定 `string \| number`，方言自行解析 |
| 打包态模块解析失败 | 方言不可用 | M1 先打通并在打包 dsh 上留一个回归用例 |
| 描述滞后被误判为 bug | 误解 | API 文档明示 + 自检套件输出提示 |
